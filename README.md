# Secure Satellite Ground Station Automation Platform

## Project Overview
A DevOps platform designed to automate software deployment,
configuration, security, and monitoring for simulated satellite
ground stations.

## Objectives
- Automate AWS infrastructure provisioning using Terraform
- Containerize applications using Docker
- Deploy applications to Kubernetes using Helm
- Build CI/CD pipelines using GitHub Actions
- Configure remote Linux servers using Ansible
- Implement security scanning and secrets management
- Monitor infrastructure using Prometheus and Grafana

## Technology Stack
- AWS
- Terraform
- Docker
- Kubernetes
- Helm
- GitHub Actions
- Ansible
- Python
- Prometheus and Grafana
